# Sales Data Analysis | Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on analyzing sales data using Python and Exploratory Data Analysis (EDA) to identify trends, patterns, and insights from the dataset.

## Objectives
- Understand and explore the sales dataset.
- Perform data cleaning and preprocessing.
- Analyze sales trends and patterns.
- Explore relationships between sales-related variables.
- Create charts and visualizations to understand the data.
- Generate meaningful insights from sales data.

## Exploratory Data Analysis
- Dataset inspection and summary statistics
- Missing value analysis
- Univariate and bivariate analysis
- Sales distribution analysis
- Relationship analysis using charts
- Data visualization and pattern identification

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project File
- `project.ipynb` — Jupyter Notebook containing the EDA, analysis, and visualizations.

## Key Learnings
- Data cleaning and preprocessing
- Exploratory Data Analysis
- Data visualization
- Identifying trends and patterns
- Extracting insights from sales data
